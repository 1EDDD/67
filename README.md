## Features

- Read Device Resolution
- Custom Resolution
- iPhone & iPad Presets
- Backup Original Resolution
- Restore Original Resolution

## Supported iOS Versions

- iOS 18.0 – 27.0.1
- iOS 27.2 Beta 1 / Beta 2

## Installation

Download the latest unsigned IPA from [Releases](https://github.com/raad67/67/releases) and install it using **SideStore** or **LiveContainer**.

## Usage

1. Open 67.
2. Import your Airlift pairing file.
3. Read your device resolution.
4. Select a preset or enter a custom resolution.
5. Apply the changes.
6. Respring your device.

## Disclaimer

Use at your own risk. Always keep a backup of your original display configuration.
